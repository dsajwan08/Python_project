# Python Mini Projects

This repository contains two beginner-friendly Python console-based projects:

1. **Student Management System**
2. **Contact Book**

These projects demonstrate basic Python programming concepts such as functions, loops, conditional statements, lists, dictionaries, and user input.

## 📌 Project 1: Student Management System

The Student Management System is a simple Python application that allows users to manage student records through a menu-driven interface.

### Features
- **Add Student:** Add a new student with roll number, name, age, and course.
- **View Students:** Display all student records.
- **Search Student:** Search for a student using their roll number.
- **Delete Student:** Delete a student record using their roll number.
- **Exit:** Close the application.

### Student Information
Each student record contains:
- Roll Number
- Name
- Age
- Course

### How It Works
The program stores student records in a Python list of dictionaries. Users can select options from the menu to perform different operations.

## 📌 Project 2: Contact Book

The Contact Book is a simple Python application used to store and manage contact information.

### Features
- **Add Contact:** Add contact details, including name, phone number, and email.
- **View Contacts:** Display all saved contacts.
- **Search Contact:** Find a contact using their name.
- **Delete Contact:** Remove a contact using their name.
- **Exit:** Close the application.

### Contact Information
Each contact contains:
- Name
- Phone Number
- Email Address

### How It Works
The program stores contact information in a Python dictionary, using the contact name as the key and phone number and email as values.
